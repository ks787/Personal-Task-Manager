# Commit Strategy

The project was built incrementally following a strict commit strategy to demonstrate the development lifecycle:
1. Scaffold monorepo structure.
2. Implement backend persistence layer.
3. Add REST API routes and validation.
4. Add API tests.
5. Create frontend API client and state management.
6. Build UI components.
7. Add loading states, toasts, and responsiveness.
8. Improve validation and error handling.
9. Add documentation.
10. Configure deployment.
